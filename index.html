Privacy Policy

History Shorts Uploader (the "Tool") is a personal automation tool used by the owner of a single YouTube channel (youtube.com/@zeyadahmed4650) to upload the owner's own original videos to that channel.

What the Tool accesses

The Tool uses the YouTube Data API (youtube.upload scope), with the channel owner's authorization, only to upload videos and set their title, description and tags on the owner's own channel.

What the Tool does not do

  • It does not collect, store, sell or share personal data of viewers or any other users.
  • It does not access the data of any Google account other than the channel owner's.
  • It does not offer any service to third parties.

Data storage

Authorization tokens are kept only in the owner's private environment and are used solely to upload videos. They are not shared with anyone.

Google API Services User Data Policy

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Tool uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy. The owner can revoke the Tool's access at any time at Google Account permissions.

Contact

Questions can be sent by opening an issue at github.com/zeyadahmed-hub/history-shorts-privacy/issues.
